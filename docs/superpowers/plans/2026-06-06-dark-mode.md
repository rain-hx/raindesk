# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add controlled three-state dark mode for rainspace with thread-safe runtime application across windows.

**Architecture:** Add a small theme model and `ThemeService`, persist `AppConfig.AppThemeMode`, define dark `ThemeDictionaries`, and register window roots for strong runtime control. UI updates are marshaled through `DispatcherQueue`.

**Tech Stack:** C#/.NET 8, WinUI 3 XAML, MSTest.
